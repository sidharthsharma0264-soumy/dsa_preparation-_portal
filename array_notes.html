Array Notes

1. What is an Array?

An array is a linear data structure that stores multiple elements of the same data type in contiguous memory locations.

Each element can be accessed using an index. In most programming languages, array indexing starts from 0.

2. Array Representation

Example:

10
Index 0
20
Index 1
30
Index 2
40
Index 3
50
Index 4

Here, the array contains 5 elements and the valid indexes are 0 to 4.

3. Array Declaration in C++

int arr[5];

int numbers[5] = {10, 20, 30, 40, 50};

4. Important Array Operations

  • Traversal: Visiting every element of the array.
  • Insertion: Adding an element at a particular position.
  • Deletion: Removing an element from the array.
  • Searching: Finding an element in the array.
  • Sorting: Arranging elements in ascending or descending order.
  • Updating: Changing the value of an existing element.

5. Array Traversal

Traversal means visiting each element of an array one by one. 

#include <iostream>
using namespace std;

int main()
{
    int arr[5] = {10, 20, 30, 40, 50};

    for(int i = 0; i < 5; i++)
    {
        cout << arr[i] << " ";
    }

    return 0;
}

Output:

10 20 30 40 50

6. Searching in an Array

Searching means finding whether a particular element exists in the array.

A simple method is Linear Search, where we check each element one by one. 

int arr[5] = {10, 20, 30, 40, 50};

int key = 30;

for(int i = 0; i < 5; i++)
{
    if(arr[i] == key)
    {
        cout << "Element found";
        break;
    }
}

7. Time Complexity

Operation Time Complexity
Access O(1)
Search O(n)
Insertion O(n)
Deletion O(n)

8. Advantages of Arrays

  • Fast access using index.
  • Easy to traverse.
  • Simple and easy to implement.
  • Efficient memory access due to contiguous storage.

9. Disadvantages of Arrays

  • Fixed-size arrays cannot easily grow or shrink.
  • Insertion and deletion can require shifting elements.
  • Unused allocated space may be wasted.
