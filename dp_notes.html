Dynamic Programming Notes

1. What is Dynamic Programming?

Dynamic Programming (DP) is an algorithmic technique used to solve complex problems by breaking them into smaller overlapping subproblems and storing their results.

2. Main Concepts

  • Overlapping Subproblems
  • Optimal Substructure
  • Memoization
  • Tabulation

3. Memoization

Memoization is a top-down approach where results of previously solved subproblems are stored and reused.

4. Tabulation

Tabulation is a bottom-up approach where a table is used to calculate solutions starting from the smallest subproblem.

5. Common DP Problems

  • Fibonacci Series
  • 0/1 Knapsack
  • Longest Common Subsequence
  • Longest Increasing Subsequence
  • Coin Change

6. C++ Example - Fibonacci

#include <iostream>
using namespace std;

int main()
{
    int n = 10;
    int dp[11];

    dp[0] = 0;
    dp[1] = 1;

    for(int i = 2; i <= n; i++)
    {
        dp[i] = dp[i-1] + dp[i-2];
    }

    cout << dp[n];

    return 0;
}

7. Advantages of Dynamic Programming

  • Reduces repeated calculations
  • Improves algorithm efficiency
  • Useful for optimization problems
  • Helps solve complex problems efficiently
