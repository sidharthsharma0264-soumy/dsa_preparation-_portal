Graph Notes

1. What is a Graph?

A graph is a non-linear data structure consisting of vertices (nodes) and edges that connect them.

2. Types of Graphs

  • Directed Graph
  • Undirected Graph
  • Weighted Graph
  • Unweighted Graph

3. Graph Representation

  • Adjacency Matrix
  • Adjacency List

4. Basic Graph Structure

|     |
