Queue Notes

1. What is a Queue?

A queue is a linear data structure that follows FIFO (First In, First Out).

2. Queue Operations

  • Enqueue: Adds an element to the queue.
  • Dequeue: Removes an element from the queue.
  • Front: Shows the first element.
  • Rear: Shows the last element.

3. Queue Structure

Front → 10 → 20 → 30 → Rear

The first inserted element is removed first.

4. C++ Example

#include <iostream>
#include <queue>
using namespace std;

int main()
{
    queue<int> q;

    q.push(10);
    q.push(20);
    q.push(30);

    cout << "Front element: " << q.front();

    q.pop();

    return 0;
}

5. Applications of Queue

  • CPU scheduling
  • Printer scheduling
  • Breadth First Search (BFS)
  • Customer service systems
  • Data buffering
