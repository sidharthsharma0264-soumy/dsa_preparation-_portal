Stack Notes

1. What is a Stack?

A stack is a linear data structure that follows LIFO (Last In, First Out).

2. Stack Operations

  • Push: Adds an element to the stack.
  • Pop: Removes the top element.
  • Peek: Shows the top element.
  • isEmpty: Checks whether the stack is empty.

3. Stack Structure

TOP → 30 → 20 → 10

The last inserted element is removed first.

4. C++ Example

#include <iostream>
#include <stack>
using namespace std;

int main()
{
    stack<int> s;

    s.push(10);
    s.push(20);
    s.push(30);

    cout << "Top element: " << s.top();

    s.pop();

    return 0;
}

5. Applications of Stack

  • Function calls
  • Undo and Redo operations
  • Expression evaluation
  • Parentheses matching
  • Backtracking
