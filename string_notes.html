String Notes

1. What is a String?

A string is a sequence of characters used to store and represent text. In C++, strings can be created using the string data type.

2. String Declaration

string name = "DSA Portal";

Here, name stores the string "DSA Portal".

3. Common String Operations

  • Finding string length
  • Concatenation
  • Comparing strings
  • Accessing characters
  • Searching characters

4. C++ Example

#include <iostream>
#include <string>
using namespace std;

int main()
{
    string name = "DSA";

    cout << "String: " << name << endl;
    cout << "Length: " << name.length();

    return 0;
}

5. Important String Functions

  • length() – Returns the length of a string.
  • size() – Returns the number of characters.
  • substr() – Extracts a part of a string.
  • find() – Searches for a character or substring.
  • append() – Adds another string.
