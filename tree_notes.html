Tree Notes

1. What is a Tree?

A tree is a non-linear data structure that represents hierarchical relationships between elements.

2. Important Terms

  • Root: The topmost node.
  • Parent: A node that has children.
  • Child: A node connected below another node.
  • Leaf: A node with no children.
  • Height: The longest path from a node to a leaf.

3. Types of Trees

  • Binary Tree
  • Binary Search Tree
  • AVL Tree
  • Heap
